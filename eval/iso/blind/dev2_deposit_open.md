# Онлайн-открытие депозита в мобильном приложении

| Поле | Значение |
|---|---|
| Наименование задачи | Онлайн-открытие срочного депозита «Накопительный+» |
| Продукт | Мобильный банк (iOS, Android) |
| Тип работы | Новая функциональность |
| Задача в JIRA | DEP-1842 |
| Заказчик | Департамент розничных продуктов |
| Версия документа | 0.9 |

## Часть A. Бизнес-требования

### 1. Описание и бизнес-цель

Сейчас клиенты банка могут открыть срочный депозит только в отделении. Цель доработки — дать возможность открыть депозит «Накопительный+» в мобильном приложении без визита в отделение и довести долю онлайн-открытий до 60% от всех открытий депозитов в течение 12 месяцев после запуска.

Депозит открывается только в тенге (KZT). Срок размещения — 3, 6 или 12 месяцев. Минимальная сумма первоначального взноса — 50 000 тенге, максимальная — 20 000 000 тенге.

Открыть депозит может клиент — физическое лицо, резидент РК, достигший 18 лет, у которого в банке есть активный текущий или карточный счёт.

### 2. Термины

| Термин | Определение |
|---|---|
| Депозит | Срочный сберегательный вклад «Накопительный+» |
| Капитализация | Присоединение начисленного вознаграждения к сумме депозита |
| ГЭСВ | Годовая эффективная ставка вознаграждения |
| Счёт списания | Текущий или карточный счёт клиента, с которого средства переводятся на депозит |
| OTP | Одноразовый код подтверждения, направляемый в SMS |

### 3. Функциональные требования

**Ф-1. Выбор условий.** Клиент выбирает срок (3, 6 или 12 месяцев), сумму взноса, счёт списания и способ получения вознаграждения: ежемесячная капитализация или ежемесячная выплата на счёт списания.

**Ф-2. Расчёт дохода.** На экране выбора условий приложение показывает прогнозируемый доход за весь срок. Расчёт выполняется по номинальной ставке с учётом выбранного способа получения вознаграждения.

**Ф-3. Ставки.** Действуют следующие ставки вознаграждения:

| Срок | Номинальная ставка | ГЭСВ |
|---|---|---|
| 3 месяца | 14,5% | 15,5% |
| 6 месяцев | 15,0% | 16,1% |
| 12 месяцев | 15,5% | 16,6% |

Ставки утверждаются Комитетом по управлению активами и пассивами. Изменение ставок не затрагивает уже открытые депозиты.

**Ф-4. Проверка суммы.** Если введённая сумма меньше минимальной или больше максимальной, кнопка «Открыть депозит» неактивна, под полем отображается подсказка с допустимым диапазоном. Если на счёте списания недостаточно средств, приложение показывает сообщение «Недостаточно средств на счёте».

**Ф-5. Подтверждение.** Перед открытием клиент знакомится с договором присоединения и подтверждает открытие OTP-кодом. Код действует 5 минут, допускается не более 3 попыток ввода.

**Ф-6. Открытие.** После подтверждения система открывает депозитный счёт, переводит средства со счёта списания, показывает экран успеха с номером депозита, добавляет депозит в список продуктов клиента, отправляет push-уведомление и направляет PDF договора на e-mail клиента.

**Ф-7. Пополнение.** Депозит можно пополнять в течение первых 2 месяцев с даты открытия. Минимальная сумма пополнения — 10 000 тенге. Пополнение выполняется со счёта списания или с любого другого счёта клиента.

**Ф-8. Досрочное расторжение.** Клиент может расторгнуть депозит досрочно в приложении. При досрочном расторжении вознаграждение пересчитывается по сниженной ставке. Если депозит расторгнут в первые 30 дней с даты открытия, вознаграждение не выплачивается.

**Ф-9. Частичное изъятие.** Частичное изъятие средств с депозита не предусмотрено. Доступно только полное закрытие.

**Ф-10. Окончание срока.** По окончании срока депозит пролонгируется на тот же срок при необходимости.

**Ф-11. Лимит количества.** Один клиент может иметь не более 3 открытых депозитов «Накопительный+» одновременно.

**Ф-12. История.** На экране депозита клиент видит историю операций: взнос, пополнения, капитализацию и выплаты вознаграждения.

**Ф-13. Дата открытия.** Датой открытия считается дата подтверждения OTP. Депозит, открытый после 23:00, считается открытым следующим календарным днём. Капитализация выполняется в последний календарный день каждого месяца.

### 4. Нефункциональные требования

| № | Требование |
|---|---|
| НФ-1 | Экран расчёта дохода должен загружаться быстро. |
| НФ-2 | Система должна выдерживать высокую нагрузку в период маркетинговых акций. |
| НФ-3 | Доступность сервиса открытия депозитов — не менее 99,9% в календарный месяц. |
| НФ-4 | Все операции открытия, пополнения и расторжения логируются. Срок хранения логов уточняется. |
| НФ-5 | Время обработки запроса на открытие — не более 3 секунд для 95% запросов при нагрузке до 50 запросов в секунду. |

### 5. Интеграции

| Система | Назначение |
|---|---|
| АБС | Открытие депозитного счёта, списание средств, начисление вознаграждения |
| SMS-шлюз | Отправка OTP-кодов |
| Сервис уведомлений | Push-уведомления клиенту |
| Сервис документов | Формирование PDF договора присоединения |

### 6. Критерии приемки

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Открытие депозита на 6 месяцев на сумму 100 000 тенге с капитализацией | Депозит открыт, показан экран успеха с номером депозита |
| 2 | Ввод суммы 40 000 тенге | Кнопка «Открыть депозит» неактивна, показана подсказка |
| 3 | Ввод OTP-кода через 4 минуты после отправки | Код отклонён как просроченный, предложено запросить новый код |
| 4 | Пополнение депозита на 12 месяцев на 4-м месяце срока на сумму 20 000 тенге | Пополнение зачислено, операция отображается в истории |
| 5 | Досрочное расторжение на 45-й день | Депозит закрыт, вознаграждение пересчитано |
| 6 | Попытка открыть 4-й депозит «Накопительный+» | Отказ с сообщением о превышении лимита |

## Часть B. Спецификация REST API

Базовый URL: `https://api.bank.kz/mobile`. Авторизация — заголовок `Authorization: Bearer <token>`.

### B.1 Получение ставок

`GET /api/v1/deposits/rates`

Пример ответа (200 OK):

```json
{
  "currency": "KZT",
  "rates": [
    {"term": 3, "nominalRate": 15.0, "effectiveRate": 15.5},
    {"term": 6, "nominalRate": 15.0, "effectiveRate": 16.1},
    {"term": 12, "nominalRate": 15.5, "effectiveRate": 16.6}
  ]
}
```

### B.2 Расчёт дохода

`GET /api/v1/deposits/calculate`

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| amount | integer | да | Сумма взноса в тенге |
| term | string | да | Срок в формате `3M`, `6M`, `12M` |
| capitalization | boolean | да | Признак капитализации |

```bash
curl -X GET "https://api.bank.kz/mobile/api/v1/deposits/calculate?amount=100000&term=6&capitalization=true" \
  -H "Authorization: Bearer eyJhbGciOi..."
```

Пример ответа (200 OK):

```json
{"amount": 100000, "term": 6, "income": 7738, "effectiveRate": 16.1}
```

### B.3 Открытие депозита

`POST /api/v1/deposits/open`

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| sourceAccount | string | да | IBAN счёта списания |
| amount | number | да | Сумма взноса, от 50 000 до 10 000 000 тенге |
| term | integer | да | Срок в месяцах |
| capitalization | boolean | да | Признак капитализации |
| otp | string | да | OTP-код из SMS |

```bash
curl -X POST "https://api.bank.kz/mobile/api/v1/deposits/open?otp=482913&iin=900101300123" \
  -H "Authorization: Bearer eyJhbGciOi..." \
  -H "Content-Type: application/json" \
  -d '{"sourceAccount": "KZ12722C000012345678", "amount": 100000, "term": 6, "capitalization": true}'
```

Пример успешного ответа (200 OK):

```json
{"depositId": "D-778812", "status": "OPENED", "openDate": "2026-12-01"}
```

Пример ответа при недостатке средств (200 OK):

```json
{"status": "ERROR", "code": "INSUFFICIENT_FUNDS", "message": "Недостаточно средств на счёте"}
```

Пример ответа при превышении лимита (400 Bad Request):

```json
{"code": "DEPOSIT_LIMIT_EXCEEDED", "message": "Превышен лимит: не более 5 депозитов на клиента"}
```

### B.4 Пополнение депозита

`POST /api/v1/deposits/{depositId}/topup`

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| depositId | string | да (path) | Идентификатор депозита |
| sourceAccount | string | да | IBAN счёта, с которого выполняется пополнение |
| amount | number | да | Сумма пополнения, не менее 10 000 тенге |

Сервис находит депозит по `depositId` и зачисляет на него сумму с указанного счёта.

### B.5 Досрочное расторжение

`GET /api/v1/deposits/{depositId}/close`

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| depositId | string | да (path) | Идентификатор депозита |
| amount | number | нет | Сумма изъятия; если не указана, депозит закрывается полностью |

### B.6 Коды ответов

| Код | Значение |
|---|---|
| 200 | Успешная обработка |
| 400 | Ошибка валидации параметров |
| 401 | Не авторизован |
| 500 | Внутренняя ошибка сервера |
