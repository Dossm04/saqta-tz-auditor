### Цели
Повысить активность использования дебетовых карт за счёт возможности ежемесячно выбирать категории покупок с повышенным кешбэком.

### Архитектура решения
Мобильное приложение → API-шлюз → сервис лояльности. Карточный процессинг → сервис лояльности (поток операций). Сервис лояльности → АБС (зачисление кешбэка на бонусный счёт) → сервис уведомлений.

### Дизайн процесса UI
Карты → Кешбэк → «Выбрать категории». На экране показан список доступных категорий с процентом кешбэка. Клиент отмечает до 4 категорий и нажимает «Сохранить». Ниже показывается сумма начисленного кешбэка за текущий месяц и прогресс до максимальной суммы.

### Требования к изменениям

#### BPMN схема процесса
Открытие периода выбора → выбор категорий клиентом → фиксация выбора → учёт покупок за месяц → расчёт кешбэка → зачисление → уведомление → завершение.

#### Функциональные требования
* **Ф-1.** Клиент с активной дебетовой картой в тенге выбирает до 3 повышенных категорий на календарный месяц.
* **Ф-2.** Выбор категорий доступен в начале месяца. После сохранения выбор фиксируется и не может быть изменён до конца месяца.
* **Ф-3.** Базовый кешбэк на все покупки — 1 %. Повышенный кешбэк по выбранным категориям — по таблице категорий.
* **Ф-4.** По окончании месяца система рассчитывает кешбэк, зачисляет его на бонусный счёт, отправляет клиенту push и отражает начисление в выписке.
* **Ф-5.** Максимальная сумма кешбэка — 10 000 ₸ в месяц на клиента.
* **Ф-6.** Кешбэк рассчитывается от суммы покупки.
* **Ф-7.** Кешбэк не начисляется на переводы, снятие наличных, оплату коммунальных услуг и прочие операции по решению банка.
* **Ф-8.** Кешбэк зачисляется после окончания месяца в разумные сроки.
* **Ф-9.** Если клиент не выбрал категории, начисляется только базовый кешбэк.

### Sequence Diagram
Приложение → сервис лояльности: сохранить категории. Процессинг → сервис лояльности: проведённая покупка (сумма, MCC). В конце месяца сервис лояльности → АБС: зачислить кешбэк. Сервис лояльности → сервис уведомлений: push «Начислен кешбэк».

### Нефункциональные требования
* Сервис лояльности должен быть надёжным и выдерживать пиковые нагрузки в праздничные периоды.
* Сервис лояльности сохраняет в журнал каждую обработанную покупку с ФИО клиента, полным номером карты и суммой — для разбора обращений.

### Требования к данным
Хранить идентификатор клиента, месяц, выбранные категории, дату выбора, сумму покупок по категориям, сумму начисленного кешбэка в тенге, признак достижения максимума.

## Часть B. REST API

Дочерний документ части A: «Категории кешбэка — REST API».

### Общие параметры

| Поле | Значение |
| :--- | :--- |
| **Description** | Сохранение выбранных категорий кешбэка |
| **REST type** | GET |
| **Authorization** | Bearer, сессия клиента |
| **Controller** | CashbackController |
| **URL type** | Dev / Prod |
| **Request URL** | Dev: `/cashback/categories/save` . Prod: `/api/v2/cashback/categories/save` |
| **CURL** | `curl -G "$BASE/cashback/categories/save" -H "Authorization: Bearer $TOKEN" --data 'clientId=556071&month=2026-12&categories=CAFE,TAXI'` |
| **Swagger** | — |
| **Gitlab project** | loyalty/cashback-service |
| **Developer** | Команда лояльности |

### Логика работы метода
1. Проверить сессию.
2. Проверить, что период выбора для месяца `month` открыт.
3. Проверить количество категорий.
4. Сохранить выбор для клиента `clientId`.
5. Вернуть сохранённые категории.

### Особые правила
1. Допускается не более 5 категорий.
2. Повторный вызов в том же месяце заменяет ранее сохранённый выбор.

### Параметры запроса

#### Query-параметры

| Parameter | Format | Size | Mandatory | Logic | Description | DB field |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `clientId` | string | 1–20 | Да | — | Идентификатор клиента | `client_id` |
| `month` | string | 7 | Да | ГГГГ-ММ | Месяц выбора | `period` |
| `categories` | string | 1–200 | Да | Коды через запятую | Выбранные категории | `categories` |

### Ответ

| Parameter | Format | Logic | Description | DB field |
| :--- | :--- | :--- | :--- | :--- |
| `month` | string | ГГГГ-ММ | Месяц выбора | `period` |
| `categories` | array | Коды категорий | Сохранённые категории | `categories` |

### Статусы

**200.** Категории сохранены.  
**422.** Превышено допустимое количество категорий.  
**401.** Требуется авторизация.

#### 200. Successful
```json
{"month":"2026-12","categories":["CAFE","TAXI"]}
```

#### 400. Bad request
```json
{"message":"Можно выбрать не более 5 категорий"}
```

#### 401. Unsuccessful — Unauthorized
```json
{"message":"Требуется вход"}
```
