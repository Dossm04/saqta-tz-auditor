## Часть A. Бизнес-требования

### 1. Описание и бизнес-цель

Школы города ведут бумажные журналы, а родители узнают об оценках детей с опозданием. Цель — перевести все 120 общеобразовательных школ города на электронный журнал и дать ученикам и родителям доступ к оценкам, домашним заданиям и посещаемости в реальном времени. Целевой показатель — 90% родителей ежемесячно заходят в дневник к концу учебного года.

### 2. Роли

### 3. Функциональные требования

**Ф-1. Оценки.** Учитель выставляет оценки за урок по пятибалльной шкале: 2, 3, 4, 5. Оценка привязывается к уроку, ученику и виду работы (устный ответ, самостоятельная, контрольная).

**Ф-2. Исправление оценки.** Учитель может исправить выставленную оценку в течение 3 дней после даты урока. После этого исправить оценку может только завуч. Все исправления сохраняются в истории с указанием автора и времени.

**Ф-3. Итоговая оценка.** Итоговая оценка за четверть рассчитывается как среднее арифметическое всех оценок ученика по предмету за четверть.

**Ф-4. Доступ к оценкам.** Ученик видит только свои оценки. Родитель видит только оценки своих детей.

**Ф-5. Домашние задания.** Учитель публикует домашнее задание к уроку. Ученик видит задание и может приложить файл с выполненной работой. Допустимые форматы — PDF, JPG, PNG; максимальный размер файла уточняется.

**Ф-6. Уведомления родителям.** Родитель получает push-уведомление в течение 5 минут после выставления ребёнку оценки ниже 3.

**Ф-7. Пропуски.** Учитель отмечает отсутствие ученика на уроке, родитель прикладывает справку или объяснительную, классный руководитель подтверждает уважительную причину, а система пересчитывает статистику посещаемости класса.

**Ф-8. Экспорт.** Завуч выгружает ведомость успеваемости класса за четверть в форматах Excel и PDF.

**Ф-9. Закрытие учебного года.** По окончании учебного года журнал закрывается для редактирования. Данные закрытых журналов хранятся в архиве при необходимости.

**Ф-10. Замещение.** При замене урока оценки за этот урок может выставлять замещающий учитель.

**Ф-11. Комментарий.** К оценке учитель может добавить комментарий длиной до 500 символов. Комментарий видят ученик и родитель.

### 4. Нефункциональные требования

| № | Требование |
|---|---|
| НФ-1 | Журнал должен работать быстро, в том числе в начале четверти. |
| НФ-2 | Система должна выдерживать пиковые нагрузки в утренние часы с 08:00 до 09:00. |
| НФ-3 | Данные учеников являются персональными данными несовершеннолетних; доступ к ним предоставляется строго в соответствии с ролями. |
| НФ-4 | Доступность платформы в учебное время — не менее 99% в месяц. |
| НФ-5 | Все действия с оценками фиксируются в журнале аудита. |

### 5. Интеграции

| Система | Назначение |
|---|---|
| Городская система учёта контингента | Списки школ, классов, учеников и связей «родитель — ребёнок» |
| Сервис уведомлений | Push-уведомления родителям; уведомления отправляются пакетно один раз в сутки в 20:00 |
| Единый вход (SSO) | Аутентификация учителей и сотрудников школы |

### 6. Критерии приемки

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Учитель выставляет ученику оценку 4 за устный ответ | Оценка отображается у ученика и у родителя |
| 2 | Учитель исправляет оценку через 5 дней после урока | Оценка исправлена, исправление сохранено в истории |
| 3 | Ученику выставлена оценка 2 | Родитель получил push-уведомление |
| 4 | Оценки ученика за четверть: 4, 3, 3, 2 | Итоговая оценка за четверть — 4 |
| 5 | Учитель отмечает пропуск, родитель прикладывает справку | Пропуск отмечен как уважительный |
| 6 | Родитель пытается открыть оценки чужого ребёнка | Доступ запрещён |

## Часть B. Спецификация REST API

Базовый URL: `https://api.school-online.ru`. Авторизация — заголовок `Authorization: Bearer <token>`.

### B.1 Аутентификация родителя и ученика

`GET /api/v1/auth`

```bash
curl -X GET "https://api.school-online.ru/api/v1/auth?login=ivanova.m&password=Qwerty123"
```

Пример ответа (200 OK):

```json
{"token": "eyJhbGciOi...", "role": "parent", "expiresIn": 86400}
```

### B.2 Выставление оценки

`POST /api/v1/grades`

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| studentId | integer | да | Идентификатор ученика |
| lessonId | integer | да | Идентификатор урока |
| grade | integer | да | Оценка, от 1 до 5 |
| workType | string | да | `oral`, `independent`, `test` |
| comment | string | нет | Комментарий, не более 255 символов |

```bash
curl -X POST "https://api.school-online.ru/api/v1/grades" \
  -H "Authorization: Bearer eyJhbGciOi..." \
  -H "Content-Type: application/json" \
  -d '{"studentId": "st-2231", "lessonId": 77120, "grade": 4, "workType": "oral"}'
```

Пример ответа (201 Created):

```json
{"gradeId": 990431, "studentId": 2231, "grade": 4, "createdAt": "2026-11-25T10:42:00+05:00"}
```

Пример ответа, если журнал закрыт (200 OK):

```json
{"error": "LESSON_CLOSED", "message": "Журнал закрыт для редактирования"}
```

### B.3 Исправление оценки

`PUT /api/v1/grades/{gradeId}`

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| gradeId | integer | да (path) | Идентификатор оценки |
| grade | integer | да | Новое значение оценки |

Сервис обновляет значение оценки по `gradeId`.

### B.4 Оценки ученика

`GET /api/v1/students/{studentId}/grades?quarter=2`

Доступно ролям «ученик» и «родитель». Возвращает все оценки ученика с указанным `studentId` за четверть.

### B.5 Удаление оценки

`GET /api/v1/grades/delete?gradeId=990431`

### B.6 Экспорт ведомости

`GET /api/v1/reports/export`

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| classId | integer | да | Идентификатор класса |
| quarter | integer | да | Номер четверти, 1–4 |
| format | string | да | `xlsx` или `csv` |

### B.7 Коды ответов

| Код | Значение |
|---|---|
| 200 | Успешная обработка |
| 201 | Ресурс создан |
| 400 | Ошибка валидации |
| 500 | Внутренняя ошибка сервера |
