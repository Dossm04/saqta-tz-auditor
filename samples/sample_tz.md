# Техническое задание: мобильное приложение «DemoBank Mobile»

## 1. Общие сведения

Заказчик: АО «Демо Банк». Исполнитель: внутренняя команда разработки.
Назначение: мобильное приложение для физических лиц, позволяющее открывать счёт, выпускать карту и совершать переводы.
Цель проекта — привлечь молодую аудиторию и сделать самый удобный банк в Казахстане.

## 2. Пользователи системы

Клиент — физическое лицо, резидент РК, старше 18 лет.
Администратор — сотрудник банка, управляющий настройками приложения через веб-панель.

## 3. Функциональные требования

### 3.1 Регистрация и онбординг

FR-01. Клиент регистрируется по номеру телефона и ИИН.
FR-02. Система проверяет данные клиента в ГБД ФЛ.
FR-03. Клиент делает селфи и фотографирует удостоверение личности; система сверяет лицо с фото документа.
FR-04. Фото селфи и удостоверения сохраняются в архиве бессрочно для последующих проверок.
FR-05. После успешной проверки автоматически открывается текущий счёт в тенге.

### 3.2 Вход в приложение

FR-06. Вход выполняется по логину и паролю либо по 4-значному ПИН-коду.
FR-07. При первом входе с нового устройства клиент вводит SMS-код.
FR-08. Временный пароль при восстановлении доступа отправляется клиенту на e-mail.
FR-09. Пароль хранится в базе данных в виде хэша MD5.

### 3.3 Карты

FR-10. Клиент может выпустить виртуальную карту Visa в приложении.
FR-11. Клиент может привязать карту другого банка для пополнения счёта.
FR-12. Для удобства повторных платежей система сохраняет номер карты, срок действия и CVV привязанной карты.
FR-13. Реквизиты виртуальной карты отображаются на отдельном экране.

### 3.4 Переводы

FR-14. Переводы по номеру телефона между клиентами банка выполняются мгновенно.
FR-15. Переводы на карты других банков РК выполняются через процессинг.
FR-16. Суточный лимит переводов составляет 500 000 тенге.
FR-17. Переводы до 50 000 тенге выполняются без подтверждения для удобства клиента.
FR-18. Каждая операция подтверждается SMS-кодом.
FR-19. Комиссия за переводы на карты других банков — 0,95%, но не менее 200 тенге.
FR-20. История операций отображается в приложении и т.д.

### 3.5 Маркетинг

FR-21. Данные клиентов (ФИО, телефон, ИИН) передаются партнёрам банка для персональных предложений.
FR-22. Push-уведомления отправляются при необходимости.

## 4. Нефункциональные требования

NFR-01. Приложение должно работать быстро и быть интуитивно понятным.
NFR-02. Доступность сервиса — 99.9%.
NFR-03. Система должна выдерживать большое количество пользователей.
NFR-04. Данные клиентов должны храниться надёжно и безопасно.
NFR-05. Все соединения выполняются по протоколу HTTPS.
NFR-06. Все запросы к процессингу, включая номер карты, записываются в лог для разбора инцидентов.
NFR-07. Поддерживаемые платформы: iOS 15+ и Android 9+.

## 5. Интеграции

- АБС банка — открытие счетов, проводки.
- Процессинговый центр — выпуск карт и переводы на карты.
- ГБД ФЛ — проверка данных клиента.
- SMS-шлюз — отправка кодов.
